# EN2KR4GAMING - 실시간 게임 음성 번역 오버레이 (v2)

해외 유저와의 음성 채팅을 실시간으로 번역해 게임 화면 위에 오버레이로 표시하는 프로그램입니다.
선택한 프로그램(게임)의 소리만 받아서 번역하며, 적은 VRAM으로 큰 효과를 내기 위해 외부 번역 API 키를 사용합니다.

Windows 10(22H2) / Windows 11 전용
NVIDIA GPU 권장 (그래픽 드라이버만 있으면 됨, CUDA Toolkit 설치 불필요)
  - GPU가 없거나 VRAM이 부족하면 클라우드 인식(Groq, 무료 API 키)을 쓸 수 있습니다
VB-Audio Virtual Cable 필요 없음 (v2부터 프로그램이 게임 소리를 직접 받습니다)
  - 단, 게임 효과음을 빼고 '음성 채팅만 번역'하는 모드는 VB-CABLE이 필요합니다 (프로그램에서 설치 도우미 제공)

## 시작하기

1. EN2KR4GAMING 폴더 전체를 원하는 곳에 두고 EN2KR4GAMING.exe 실행 (exe만 따로 옮기면 실행되지 않습니다)
2. '번역 API'에서 API 키 등록
3. 게임 실행 후 메인 창 '번역할 프로그램'에서 게임 선택
4. F12로 오버레이 편집 모드에 들어가 자막 위치·크기 조절, 다시 F12로 종료
5. 게임은 '테두리 없는 창 모드(Borderless)'로 실행 (독점 전체 화면에서는 오버레이가 안 보임)

## 클라우드 인식 (Groq) - GPU가 없거나 VRAM이 부족할 때

음성 인식을 내 PC 대신 Groq 서버에서 합니다. VRAM을 쓰지 않고, 문장당 약 0.3~0.9초 걸립니다.

1. 메인 창 '인식 엔진' → 실행 위치 '클라우드 · Groq' 선택
2. 'Groq API 키'에 키 입력 → '연결 테스트' (키 발급 방법은 아래, 프로그램의 '키 발급 안내' 버튼에도 있음)
3. 모델은 whisper-large-v3 (정확도 우선, 추천)

### Groq API 키 발급 (무료)
1. https://console.groq.com/keys 접속
2. Google 계정 등으로 가입·로그인 (무료 플랜은 결제 카드 등록 필요 없음)
3. API Keys 화면에서 Create API Key → 알아보기 쉬운 이름(예: EN2KR)을 넣어 만들기
4. gsk_로 시작하는 키가 나오면 바로 복사 (키는 이때 한 번만 보입니다. 놓쳤다면 새로 만드세요)
5. 프로그램의 키 입력 칸에 붙여 넣기. 같은 키를 번역 API(OpenAI 호환 → Groq)에도 쓸 수 있습니다
- 남은 한도 확인: https://console.groq.com/settings/limits
- 키를 채팅·게시판 등에 붙여 넣지 마세요. 남에게 알려졌다면 같은 화면에서 삭제하고 새로 만드세요

- 무료 한도: 하루 2,000문장 · 분당 20문장 (넘으면 한도가 풀릴 때까지 인식을 잠시 멈추고 알려 줌)
- 말소리 구간이 Groq 서버로 전송됩니다
- 키는 번역 API 키처럼 이 PC의 Windows 계정으로 암호화해서 저장합니다

## 음성 채팅만 번역 (VB-CABLE)

게임에 '음성 채팅 출력 장치'를 따로 고르는 설정이 있어야 합니다.

1. '번역할 프로그램' 맨 위의 '음성 채팅만 번역 (VB-CABLE)' 선택
2. VB-CABLE이 없으면 'VB-CABLE 설치' 버튼 → VB-Audio 설치 창에서 Install Driver → 재부팅
   (VB-CABLE은 VB-Audio의 도네이션웨어입니다. 출처: www.vb-cable.com, 유용하다면 후원해 주세요)
3. 게임의 오디오 설정: 음성 채팅 출력 장치 = CABLE Input (VB-Audio Virtual Cable)
4. '음성 채팅 듣기'를 켜 두면 프로그램이 음성 채팅을 헤드셋으로 들려줍니다
   프로그램을 쓰지 않을 때는 게임의 음성 채팅 출력 장치를 원래대로(시스템 기본값) 되돌리세요

## 번역 API

여러 개를 등록하면 위에서부터 순서대로 쓰고, 한도 초과·오류 시 다음 API로 자동 전환합니다.

### DeepL API (추천)
- 만들기 쉬움, 번역 품질 좋음
- 월 50만 자 무료
- [API 키 발급 가이드](https://support.deepl.com/hc/ko/articles/360020695820)

### Azure Translator API
- 설정이 복잡함, 한도 큼
- 월 200만 자 무료 (F0 등급), 지역(region) 입력 필요
- [API 키 발급 가이드](https://memoengine.com/docs/ai/azure-translator-service-setup-guide/)

### Google Cloud Translation
- 월 50만 자 무료
- Google Cloud 결제 계정 연결과 'Cloud Translation API' 사용 설정 필요
- 무료 한도를 넘으면 요금이 청구될 수 있으니 예산 알림을 설정하세요

### LLM (Gemini, Groq 등 OpenAI 호환 API)
- Groq 키 발급 방법은 위 'Groq API 키 발급' 참고
- 게임 슬랭과 문맥 번역에 강하지만 응답이 느림
- 무료 한도는 서비스마다 자주 바뀌고, 무료 티어는 입력 내용이 학습에 쓰일 수 있음

※ DeepL·Azure 무료 등급은 본인 인증용 해외 카드 등록이 필요하지만, 한도를 넘어도 결제가 이루어지지 않습니다.
※ 무료 한도는 바뀔 수 있으니 각 서비스 요금 페이지에서 확인하세요.

## 문제 해결

- 소리가 안 잡힘: 메인 창 상단 '오디오' 상태를 확인하고, '번역할 프로그램'에서 게임을 다시 선택
- F12가 안 먹음: 게임이 관리자 권한으로 실행 중이면 이 프로그램도 관리자 권한으로 실행
- 설정·로그·번역 기록 위치: %APPDATA%\EN2KR4GAMING (메인 창 '기록 폴더 열기')
